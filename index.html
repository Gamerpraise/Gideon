Help

What happens after I pair?

Gideon starts on your number in a few seconds and sends you a welcome message. Open any chat and type .menu. Group tools like .tagall need you (and the bot) to be a group admin.

Why are some commands locked?

This isn't a self-hosted bot — it runs on a shared server managed by the owner. So that nobody can break it for everyone else, settings and admin commands (mode, prefix, broadcast, restart…) only respond to the bot owner, on every number. Everyday commands are open to anyone who messages your bot.

What does the server keep? Can I remove it?

To run the bot, the server keeps your WhatsApp login (encrypted when a backup is configured) and bot settings. Chats are not logged — only commands are read. Type .logout confirm to delete everything, or remove the device in WhatsApp → Linked devices. Use a number you're comfortable with; a spare number works well.

The code doesn't work / no "link" option

Make sure the number is the one on that WhatsApp, with the country code and no leading 0. Update WhatsApp, then try again — or use the QR code tab instead.

Can I run a bot I fully control instead?

Yes — the Gideon source code is on GitHub. Deploy your own copy and you're the owner of that one, with every setting unlocked.
